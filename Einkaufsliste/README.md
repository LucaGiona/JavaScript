# 📝 Dynamic Item List with Delete Function (JavaScript)

A simple interactive list using HTML & JavaScript. Users can add items by typing into an input field and clicking a button or pressing "Enter". Each item can be removed using a delete button.

Eine einfache interaktive Liste mit HTML & JavaScript. Benutzer können Einträge hinzufügen, indem sie in ein Eingabefeld schreiben und entweder den Button klicken oder "Enter" drücken. Jeder Eintrag lässt sich mit einem Button wieder löschen.

---

## 🚀 Features / Funktionen

- ✅ Add new items to a list / Neue Einträge zur Liste hinzufügen  
- ⌨️ Add items with Enter key / Mit der Enter-Taste hinzufügen  
- 🗑️ Remove items individually / Einträge per Button löschen  
- 💡 Clean & dynamic DOM manipulation / Dynamische DOM-Manipulation
