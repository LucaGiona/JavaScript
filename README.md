# Projektübersicht: Web- und JavaScript-Projekte

Dies ist eine Sammlung von Mini-Projekten rund um HTML, CSS, JavaScript, Node.js und weitere moderne Webtechnologien. Jedes Unterverzeichnis enthält ein eigenes Projekt mit einer dazugehörigen `README.md`-Datei, in der die Funktionsweise, Besonderheiten und Nutzung beschrieben sind.

Diese Sammlung dient sowohl als Lernportfolio als auch als Inspiration für eigene Webanwendungen. Viele Projekte basieren auf Tutorials (z. B. YouTube-Kanälen wie *Programmier mit Mario*, *Web Dev Simplified* oder *The Net Ninja*) und wurden durch eigene Anpassungen erweitert.

## Hinweise

- Alle Projekte sind für Lernzwecke gedacht und teils durch Tutorials inspiriert oder erweitert.
- Die Ausführung von JS-basierten Projekten erfolgt meist über Live Server oder lokalen HTTP-Server (`npx http-server` o.ä.).
- Node.js-Projekte wie `ecommerce-app` erfordern `npm install` und `npm start`.
- Einige Projekte nutzen externe APIs (z. B. OMDb, Mapbox), ggf. sind API-Keys erforderlich.
