
# Todo List (Powell/Kyle)
> A beautifully styled multi-list to-do app inspired by [Kyle from Web Dev Simplified](https://www.youtube.com/@WebDevSimplified)

## Overview  
This project is a responsive and dynamic **multi-list to-do application** built with vanilla JavaScript, HTML, and CSS. Users can create multiple to-do lists, manage individual tasks, and have all data persist via `localStorage`.

The UI is carefully designed using modern CSS practices and a modular layout, providing a smooth and intuitive user experience.

---

## Features

- ✅ Create and delete **lists**
- 📝 Add, complete, and remove **tasks**
- 🔢 Live **task counter** per list
- 💾 Data persistence with `localStorage`
- 🎨 Responsive design and hover animations

---

---

## How to Use

1. **Open `index.html`** in a browser (no server required).
2. Click the `+` button to add new lists or tasks.
3. Check tasks to mark them as completed.
4. Use the buttons to clear completed tasks or delete entire lists.
5. Your data is saved automatically in the browser.

---

## Technologies Used

- **HTML5** – semantic markup
- **CSS3** – responsive design and animations
- **JavaScript (ES6+)** – event handling, state management, localStorage
